## 📌 About

Builds on [ToDo](https://github.com/wanderson1873/ToDo) with a Pro plan upgrade and validation middlewares, each covered by its own tests. A challenge from Rocketseat's **Ignite** Node.js track.

## 🧠 What I practiced

- **Composable middlewares:** check the account exists, check the plan allows another to-do, check the to-do belongs to the user.
- **Unit tests for each middleware** plus integration tests for the routes.
- **UUID validation** and clear error responses.

## 🚀 Run locally

You need Node.js and Yarn (or npm).

```bash
git clone https://github.com/wanderson1873/ToDoPRO.git
```

Run the API on `http://localhost:3333`:

```bash
cd ToDoPRO
yarn install
yarn dev
```

Run the tests:

```bash
yarn test
```
